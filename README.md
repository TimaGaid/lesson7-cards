# Два маршрути на вихідні

Дві картки на HTML і CSS для практики блокової моделі та позиціювання.

Картки мають різні внутрішні відступи (`padding`), рамки (`border`) і верхні відступи (`margin`). Завдяки `box-sizing: border-box` внутрішні відступи й рамки входять у ширину картки. Позначка «Нове» має `position: absolute` і прив’язана до другої картки через `position: relative`. Під позначкою є місце завдяки верхньому `padding`.

У Chrome DevTools на ширині 320 px обидві картки мали по 288 px, а в Box Model другої картки ширина вмісту становила 234 px. На ширинах 320 і 800 px горизонтального скролу не було, а між позначкою та заголовком залишалося 14,5 px.
